# GitHub "About" section

## Description (short, for the repo's About field)

A glassy Apple-style Now Playing music player — real audio, auto-tinted per-song ambient lighting, live equalizer, drag-to-reorder queue, liked songs, user uploads (IndexedDB), mouse/gyroscope spatial tilt, custom gradient backgrounds, and lock-screen media controls. No build step, no framework. v0.2
